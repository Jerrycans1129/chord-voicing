# Voicing · 和弦转位训练 · v0.2.0

面向实体钢琴或电子键盘的视觉训练工具。纯 HTML/CSS/JavaScript，无外部依赖、在线字体或远程资源；构建仅注入提交编号与缓存标识。支持安装为 PWA，并在首次加载、缓存完成后离线训练。

## 启动

```sh
npm start
```

默认监听 `0.0.0.0:8000`，终端显示本机与局域网地址。可用 `PORT=8001 npm start` 更换端口。手机/平板和电脑连接同一 Wi-Fi 后可访问 LAN 地址；电脑须保持运行。服务只提供 dist 中指定的应用文件，不暴露项目目录。请在可信本地网络使用。

## 界面与训练

- 主页保留名称及版本、设置图标与三层训练树。左侧竖排六个圆角矩形训练项目，右上角为开始训练；中部是跨项目连续的圆形节点链，综合节点使用更大的圆并分两行显示 Level 与名称；原位／转位组居中显示在所选和弦正下方，以垂直直线连接，随父节点滚动对齐。移除节点内容说明与上次成绩说明，节点仅显示名称和历史最高半星评级。
- 全页禁止文本选择和原生对象拖拽。鼠标横向拖动训练链（超过 6px 后按拖动处理，不误选关卡）；触屏使用原生滑动。选中关卡高亮，已评级关卡显示历史最高半星评级。叶节点均可自由训练；汇聚节点有三星条件，详见下文。没有完成按钮或通关标记；从未评级的星级区域留白。
- 设置使用 HTML 模态窗：速度、节拍器、遮挡／隐藏琴键、MIDI 连接。关闭后回到原页面；暂停中关闭不会恢复训练。暂停设置额外显示训练时间、正确／已结束题数、原始正确率和退出训练按钮。
- 训练页无计时文字。题目提前 8 拍出现，每 4 拍一题。标签触及琴键上沿时演奏；点击空白处或空格暂停，暂停显示当前答案，再次点击空白处继续。按键上的绿点是答案、蓝色是 MIDI 输入。无触屏演奏或麦克风识别。
- 五档速度：很慢 40、慢 60、标准 90、快 120、很快 140 BPM。新用户默认标准；旧速度设置迁移到最近一档。暂停修改速度不推进训练时间或视觉进度。
- 手机勾选“遮挡／隐藏琴键”时，训练中键盘下移隐藏；未勾选时始终显示。平板和桌面勾选时模糊遮挡，未勾选时清晰显示。所有设备暂停时均显示清晰琴键和答案；恢复时按设置处理。
- 30 分钟为有效训练时长，暂停与切后台不计时。中途退出或到时均结算，回到当前关卡主页。重新开始是一轮新训练，薄弱项与历史最高分保留。
- 切后台、转竖屏、全部 MIDI 输入断开时自动暂停。暂停揭示琴键与当前答案，因此同样记录本轮暂停和显示琴键条件。断开后必须重新连接 MIDI 输入设备，才能手动恢复训练。
- 横屏使用，虚拟键盘为 C3–C6，37 键。所有和弦使用密集排列，不省略或重复组成音；和弦的所有构成音须落在键盘范围内。

## 训练树与进度

- 单音：2个黑键、3个黑键、5个黑键、7个白键、Level-1／全部12个键。
- 大三/小三：大三和弦、小三和弦、Level-2／基础和弦。
- 挂留和弦：挂四和弦、挂二和弦、Level-3／开挂啦。
- 属七/小七：属七和弦、小七和弦、Level-4／高级和弦1。
- 大七/加九：大七和弦、加九和弦、Level-5／高级和弦2。
- 终极大杂烩：Level-6／满级键盘手。移除实战占位及属七挂四训练。
- 左侧项目栏只负责导航，无独立训练和评级。点击项目将中部训练链定位到该组首节点；滚动训练链按最接近可视中心的节点更新项目高亮，到两端归属首尾项目，并在左侧竖向滚动露出对应项目。浏览项目不改变实际训练选择或第三行。点击训练节点才更新选择，未解锁时禁用开始训练。
- 三音和弦第三行是根音在右、根音居中、原位；四音和弦是根音在右、根音右二、根音左二、原位。挂和弦与 add9 保留根音位置标注。
- 共 46 个可训练节点：32 个叶节点、8 个和弦类别节点和 6 个 Level 节点。单音叶节点及具体原位／转位始终可自由训练，链条只表示推荐顺序。
- 和弦类别训练要求其所有原位／转位历史最高成绩达到三星。Level-1 要求四个单音叶节点三星；Level-2 要求大三、小三类别节点三星，不要求 Level-1；Level-3～5 要求本组两个和弦类别节点和前一个 Level 三星；Level-6 要求 Level-5 三星。各节点独立评级，低分重练不覆盖最高成绩。
- Level-1 是单音识别，覆盖十二个音级（17 个音名写法），不参与和弦综合题库。Level-2 只训练大三、小三。Level-3～5 每十题打乱安排五题本组内容、五题之前全部和弦内容，各题库去重，不叠加旧 Level 题库。Level-6 在全部八种和弦中随机出题，覆盖 28 种类型与根音位置组合（476 个独立训练项）。
- 打开应用按从左到右、先原位／转位再类别节点的顺序，选择第一个未满三星且可训练的节点。全部完成后选中 Level-6；结算后停留在本次节点。
- 内容未变的单音、和弦类别、原位／转位沿用原 ID 和成绩；旧单音混合成绩保留为 Level-1。Level-2～6 使用新 ID，不继承范围不同的旧综合成绩；薄弱项继续按原题目 ID 共享。属七挂四的内部类型编号仅保留用于避免旧加九记录错位，不生成训练题。

### 和弦组成与配音

| 类别 | 符号 | 音级 |
| --- | --- | --- |
| 大三 | C | 1、3、5 |
| 小三 | Cm | 1、♭3、5 |
| 挂四 | Csus4 | 1、4、5 |
| 挂二 | Csus2 | 1、2、5 |
| 属七 | C7 | 1、3、5、♭7 |
| 小七 | Cm7 | 1、♭3、5、♭7 |
| 大七 | Cmaj7 | 1、3、5、7 |
| 加九 | Cadd9 | 1、3、5、9，不含七音 |

add9 的九音折入同一八度，保留三音，因此不是 sus2。以 C 为例，四个训练节点依次是 D3–E3–G3–C4、E3–G3–C4–D4、G3–C4–D4–E4、C4–D4–E4–G4。所有音域位置均要求每个实际琴键位于 C3–C6 内。

sus2 与 sus4 的部分配音会出现相同实际琴键，例如 Csus2 与 Gsus4；保留题目指定的和弦身份及独立薄弱项。

## 作答判定与容错

- 每题单独累计新的 MIDI Note On（力度 >0），允许任意顺序的分解和弦、重复组成音、各音之间松开。Note Off、力度为 0 的 Note On、踏板以及持续按住状态不贡献答案。按设备/通道维护物理按键，尚未松开的重复 Note On 不作为新攻击。
- 在允许的窗口内，全部目标实际琴键都被弹到，且没有需要计错的错音，才计为正确。要求指定八度和转位，不把其他八度或经过音自动视为正确。
- 未演奏、部分组成音：已结束题数 +1，正确题数不增加，不变红。普通区间非目标音：立即变红，每题只增加一次薄弱等级；后来补齐也不改判。
- 取消交接期，每题判定窗口整体提前 180ms。例如视觉区间为 8～12 秒，判定区间为 `[7.820, 11.820)` 秒；下一题从 11.820 秒开始。窗口无重叠、无空隙，每次按键只归属一题，共有音也不重复计入两题。所有窗口内的非目标音正常计错。
- 前题在提前后的截止时刻立即结算。用有效训练秒数保存已发生的切换，暂停冻结窗口。变速重新计算未来边界，已完成的切换不回退；若恢复时新速度已使下一题进入提前范围，就在恢复时切换，不追溯修改过去的判定。固定速度下窗口时长不变。
- 第一题触线前 180ms 开始正常判定（包括错音），更早的前奏输入不判题。退出/到时尚未到达判定截止时刻的题目不计入分母。
- 下落动画、视觉触线和节拍不前移。暂停显示视觉上已触线的题目及其键盘组成音；第一题触线前预览第一题。答案辅助状态归属实际展示的题目，不回溯修改已结算结果；设备断连仍按实际判定题记录辅助状态。视觉与统计分离：只有明确错音变红。未作答、未完整作答不变红；即使已经弹齐，也继续监听到窗口结束，以发现后续错音。只有已判定正确（含触线前 180ms 内判对）的标签才在触线后按当前视觉进度渐隐；未演奏、仅弹部分组成音保持原色和完整不透明度，后续错音恢复完整不透明度并变红。
- 完整、无错音且未看本题答案的正确作答，单音和和弦都降低一级薄弱等级。查看答案后完整弹对仍计入原始正确题数，但不降低薄弱等级；未弹/未弹完不升不降。

## 弹奏时机观测

设置里的「弹奏时机统计」自动记录训练中的每次有效新按键（Note On），显示视觉触线前 `[-180, 0)` ms、后 `(0, 180]` ms 和恰好触线的数量。这里的时值指按键发生时刻，不是按住时长。新记录标记为 `advance-180ms`，旧记录保留 `overlap-180ms`。设置只展示新规则统计；导出保留两种规则的原始记录和分组统计。观测不改变得分或判题。

- 使用 MIDI 事件时间戳，另存处理时刻与两者之差；缺失或无效时间戳时明确标记为 callback 回退。记录有效训练时间、音高、力度、通道、速度、关卡、实际判定题索引、答案提示及节拍器状态。消息处理延迟不等于完整的键盘／音频／屏幕硬件延迟。
- 零点是最近的实际视觉换题分界，负数表示提前，正数表示滞后。暂停时间不计入偏差，变速按实际运行时间线计算；未来分界尚不能确定时先排除，经过足够时间后再分析。开场没有前题的分界单独排除。
- 百分比分母是保留记录中可确定换题分界的全部按键，包含窗口外按键；不是仅以 ±180ms 内按键为分母。无有效样本显示「—」。显示涉及的分界数，但按键比例仍按每个组成音计数，不等于和弦比例或独立演奏次数。
- 导出的 JSON 包含原始事件、实际时间线、逐次偏差、60ms 附近分桶、按关卡／BPM／判定规则分组的统计，以及提前 80／120／180／240ms 的对比。每个候选值分别统计提前区域内仅匹配前题、仅匹配后题、共有音和均不匹配的数量。这是归属变化的线索，不是演奏意图识别，也不是重放后的正确率。
- 只保存在当前浏览器，保留最近 5,000 次按键；每 5 秒以及暂停、结束、离开页面时尝试保存。突然关闭可能丢失尚未保存的几秒数据。存储失败时设置里会提示，内存记录仍可导出。不同浏览器和设备不自动合并。
- 设置 →「导出弹奏数据」可保存原始记录及统计。也可执行 `node scripts/analyze-timing.mjs <导出文件.json>` 重新计算统计。没有真实弹奏样本时不生成效果结论。

评估 180ms 时，应同时查看提前区域的“仅匹配后题”和“仅匹配前题”，并分速度、关卡及多次练习比较；共有音无法区分意图。新旧判定规则本身也可能影响弹奏习惯，所以应分开比较，不能仅凭按键分布证明哪种规则体验更好。

## 评分

每轮只记录全局条件，结束时计算，不逐题折算：

`综合分 = 100 × 正确题数 / 已结束题数 × 暂停系数 × 琴键系数 × 速度系数 × 时长系数`

| 条件 | 系数 |
| --- | --- |
| 曾暂停 | 0.95，否则 1 |
| 曾显示清晰琴键（包括暂停） | 0.90，否则 1 |
| 最低实际运行速度：40 / 60 / 90 / 120 / 140 BPM | 0.70 / 0.85 / 1 / 1 / 1 |
| 时长 | 有效训练秒数 / 1800，最高 1 |

重复暂停、重复显示琴键不重复乘系数；恢复隐藏或调快速度不清除记录。首页操作不影响下一轮。暂停时短暂选过、恢复前又改掉的速度不算生效，只有实际运行过的速度参与最低值。

| 综合分 | 星级 |
| --- | --- |
| 0 | 0 |
| 大于 0，小于 20 | 0.5 |
| 20–不足 40 | 1 |
| 40–不足 60 | 1.5 |
| 60–不足 75 | 2 |
| 75–不足 90 | 2.5 |
| 90–100 | 3 |

父节点开放仍严格沿用此规则：最佳条件下全对至少训练 27 分钟才能三星；40/60 BPM 无法三星，暂停并揭示琴键后最高 85.5 分，无法三星。

评级用未四舍五入的分数；显示分数向下保留一位小数，避免将 89.999 显示为 90 分却只有 2.5 星。

从未成功启动，评分区域留白。成功启动后即使在第一题结束前退出，也记录 0/0、0 分、0 星，避免除零。历史最高综合分和最近一轮结果分别保存，较低成绩不覆盖历史最高星级。未连接 MIDI 而被提示拦截不算启动；只有存在连接状态为 connected 的 MIDI 输入设备才能启动或恢复训练；反复关闭提示、点击开始、空格和点击空白均不能绕过此限制。仅授予 MIDI 权限但没有输入设备，也不能启动。

## 自适应出题

- 单音训练项为具体音名，和弦为具体根音写法 × 类型 × 转位；C♯ 与 D♭ 权重完全独立，不绑定八度。同一训练项跨关卡共享薄弱等级。
- 每 10 题打乱安排 7 个均衡位置和 3 个强化机会。均衡队列为不放回洗牌袋；强化不消耗均衡条目。四个单音叶节点及单音混合分别有 4、6、10、7、17 个音名条目，Level-6 有 476 个和弦训练项；Level-3～5 在各自当前／历史题库内独立均衡抽题，强化机会仅从当题所属题库选择，保持 50% 配比。
- 薄弱等级 0–3，强化权重 0、1、3、7。按明确错音升一级，可靠完整正确降一级；等级有上限，不随时间自行降低。
- 强化候选距上次出现至少隔开 3 道题；不足则回退为均衡题。30% 是强化机会，不是保证的实际强化题比例。冷却只约束强化来源。
- 每项另有合法八度洗牌袋，保证该项各合法八度累计出现次数差最多 1。逐题生成，屏幕上已出现的题目不替换。
- 设计借鉴逐项记录和错后复习的做法，是面向连续演奏的启发式调度，不宣称为 SM-2 或 FSRS 原算法。

## MIDI 与 PWA

使用 HTTPS 或本机 localhost 连接 Web MIDI，浏览器需要提供 `navigator.requestMIDIAccess`。局域网普通 HTTP 不提供安全上下文。支持多设备、多通道、热插拔；延音不延长物理按键高亮。断开或切后台清除对应输入。可在设置中“清除亮键”恢复漏发松键消息的设备。

启动前未连接 MIDI 的提示是网页 HTML 模态窗，不调用浏览器 alert。提示打开时背景操作不会启动或重复累计次数，关闭不自动开始训练。

通过浏览器菜单安装 PWA（Safari 可添加到主屏幕/程序坞，其他支持浏览器使用安装入口）。首次联网缓存后可离线使用。更新静态资源时递增 `dist/sw.js` 缓存版本；关闭所有旧窗口后重新打开生效，不在训练中强制刷新。

设置、薄弱项和成绩保存在本机浏览器，不跨设备同步。清除网站数据会清除记录。存储不可用时仍可训练，但无法持久保存。

应用版本由 `dist/scoring.js` 的 VERSION 与 package.json 一致管理；本次从 0.1.0 更新为 0.2.0。第二位用于功能迭代、第三位用于修复；第一位升级需用户明确同意。缓存版本是独立资源更新序号。

- 1,400,140 个评分组合：正确率以 0.01 个百分点递增，遍历五档速度、暂停/键盘条件、七种时长。
- 10,000 条随机设置历史：包含反复暂停、反复显示琴键、变速和暂停期间未实际运行的速度。
- 60,000 轮随机训练，共 20,935,200 道作答，六种成功概率、五档速度、五种时长与四种辅助模式。
- 1,000,000 次分界附近的 Note On，按五档速度验证提前切换、唯一归属、共有音不重复计分和非目标音正常计错。
- 所有断言通过：无除零/非有限分数，正确率提高不会降分，时间折算严格线性，系数只应用一次，最低速度不被之后调快覆盖，原始正确率不被难度系数修改，提前切换后不再向前题累计命中。

| 全对的训练情景 | 综合分 | 星级 |
| --- | --- | --- |
| 标准、完整、隐藏琴键、未暂停 | 100 | 3 |
| 标准、完整、暂停过（同时显示琴键） | 85.5 | 2.5 |
| 慢速、完整、显示琴键 | 76.5 | 2.5 |
| 很慢、完整、显示琴键 | 63 | 2 |
| 标准、无辅助、15/30 分钟 | 50 | 1.5 |
| 标准、无辅助、27/30 分钟 | 90 | 3 |
| 标准、完整、仅显示琴键 | 90 | 3 |

后两项是既定系数的边界结果：并非一切辅助都绝对禁止三星，也并非三星一定要求练满 30 分钟。无需额外隐藏规则。

在潜在答对概率为 90% 的 100 轮标准完整模拟中，45 轮为 2.5 星、55 轮为 3 星；潜在概率 95% 的 100 轮全部为三星。阈值附近存在有限题数造成的正常波动，不能将一次星级视为精确的能力估计。

这些模拟验证算法一致性和系数的可解释后果，不验证真实学习收益，也不能证明系数是最佳值。无辅助且速度更快可能做更多题，但不额外加分；本应用评估的是窗口内目标音是否完整且无错音，不评估具体节奏、音符时长或音乐表达。
