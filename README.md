# Voicing · 和弦转位训练 · v0.2.0

面向实体钢琴或电子键盘的视觉训练工具。纯 HTML/CSS/JavaScript，无外部依赖、在线字体或远程资源；构建仅注入提交编号与缓存标识。支持安装为 PWA，并在首次加载、缓存完成后离线训练。

## 启动

```sh
npm start
```

默认监听 `0.0.0.0:8000`，终端显示本机与局域网地址。可用 `PORT=8001 npm start` 更换端口。手机/平板和电脑连接同一 Wi-Fi 后可访问 LAN 地址；电脑须保持运行。服务只提供 dist 中指定的应用文件，不暴露项目目录。请在可信本地网络使用。

## 界面与训练

- 主页保留名称及版本、设置图标与三层训练树。左侧竖排六个圆角矩形训练项目，右上角为开始训练；中部是跨项目连续的圆形节点链，综合节点使用更大的圆并分两行显示 Level 与名称；原位／转位组居中显示在所选和弦正下方，以垂直直线连接，随父节点滚动对齐。移除节点内容说明与上次成绩说明，节点仅显示名称和历史最高半星评级。
- 全页禁止文本选择和原生对象拖拽。鼠标横向拖动训练链（超过 6px 后按拖动处理，不误选关卡）；触屏使用原生滑动。选中关卡高亮，已评级关卡显示历史最高半星评级。叶节点均可自由训练；汇聚节点有三星条件，详见下文。没有完成按钮或通关标记；从未评级的星级区域留白。
- 训练与闯关共用轨道、演奏区和隐藏琴键布局，训练默认 90 BPM，使用大号加减按钮在 40–180 BPM 间每次调整 10；闯关固定 120 BPM。训练与闯关默认节拍开；设置仅在当前页面暂存。
- 每个标签间隔四拍，提前八拍出现。标签底边触及上界线后，以演奏区高度／四拍时长的速度下落；下一标签触及上界线时，前一标签底边恰好抵达下界线，此后停在底线，原位用 180ms 淡出，不再越过底线。
- 训练标签触及上界线时一律继续下落，在整小节检测期内允许反复作答，弹错标红、重新完整弹对恢复正常。训练不模糊、不计分。窗口结束仍未答对则在底线冻结整列，等待当前标签重新弹对，再预备一小节后继续。闯关持续下落，演奏区内模糊，错误按当前题计入正确率；没有错音方块或堆满失败规则。
- 顶部显示关卡名称，训练显示练习用时，闯关显示 30 分钟倒计时。训练自动冻结仍累计练习用时，手动暂停停止计时。训练无时限；闯关最后标签到底淡出后再空四拍弹出评分，手动退出即时结算。
- 点击画面或空格暂停，训练和闯关虚化背景，训练显示继续、设置、退出，闯关仅显示继续、退出。
- 切后台、转竖屏、全部 MIDI 输入断开时自动暂停；恢复须有已连接的 MIDI 输入。手机继续要求横屏。
- 横屏使用，虚拟键盘为 C3–C6，37 键。所有和弦使用密集排列，不省略或重复组成音；和弦的所有构成音须落在键盘范围内。

## 训练树与进度

- 单音：2个黑键、3个黑键、5个黑键、7个白键、Level-1／全部12个键。
- 大三/小三：大三和弦、小三和弦、Level-2／基础和弦。
- 挂留和弦：挂四和弦、挂二和弦、Level-3／开挂啦。
- 属七/小七：属七和弦、小七和弦、Level-4／高级和弦1。
- 大七/加九：大七和弦、加九和弦、Level-5／高级和弦2。
- 终极大杂烩：Level-6／满级键盘手。移除实战占位及属七挂四训练。
- 左侧项目栏只负责导航，无独立训练和评级。点击项目将中部训练链定位到该组首节点；滚动训练链按最接近可视中心的节点更新项目高亮，到两端归属首尾项目，并在左侧竖向滚动露出对应项目。浏览项目不改变实际训练选择或第三行。点击训练节点才更新选择，未解锁时禁用开始训练。
- 三音和弦第三行是根音在右、根音居中、原位；四音和弦是根音在右、根音右二、根音左二、原位。挂和弦与 add9 保留根音位置标注。
- 共 46 个可训练节点：32 个叶节点、8 个和弦类别节点和 6 个 Level 节点。单音叶节点及具体原位／转位始终可自由训练，链条只表示推荐顺序。
- 和弦类别训练要求其所有原位／转位历史最高成绩达到三星。Level-1 要求四个单音叶节点三星；Level-2 要求大三、小三类别节点三星，不要求 Level-1；Level-3～5 要求本组两个和弦类别节点和前一个 Level 三星；Level-6 要求 Level-5 三星。各节点独立评级，低分重练不覆盖最高成绩。
- Level-1 是单音识别，覆盖十二个音级（17 个音名写法），不参与和弦综合题库。Level-2 只训练大三、小三。Level-3～5 每十题打乱安排五题本组内容、五题之前全部和弦内容，各题库去重，不叠加旧 Level 题库。Level-6 在全部八种和弦中随机出题，覆盖 28 种类型与根音位置组合（476 个独立训练项）。
- 打开应用按从左到右、先原位／转位再类别节点的顺序，选择第一个未满三星且可训练的节点。全部完成后选中 Level-6；结算后停留在本次节点。
- 内容未变的单音、和弦类别、原位／转位沿用原 ID 和成绩；旧单音混合成绩保留为 Level-1。Level-2～6 使用新 ID，不继承范围不同的旧综合成绩；薄弱项继续按原题目 ID 共享。属七挂四的内部类型编号仅保留用于避免旧加九记录错位，不生成训练题。

### 和弦组成与配音

| 类别 | 符号 | 音级 |
| --- | --- | --- |
| 大三 | C | 1、3、5 |
| 小三 | Cm | 1、♭3、5 |
| 挂四 | Csus4 | 1、4、5 |
| 挂二 | Csus2 | 1、2、5 |
| 属七 | C7 | 1、3、5、♭7 |
| 小七 | Cm7 | 1、♭3、5、♭7 |
| 大七 | Cmaj7 | 1、3、5、7 |
| 加九 | Cadd9 | 1、3、5、9，不含七音 |

add9 的九音折入同一八度，保留三音，因此不是 sus2。以 C 为例，四个训练节点依次是 D3–E3–G3–C4、E3–G3–C4–D4、G3–C4–D4–E4、C4–D4–E4–G4。所有音域位置均要求每个实际琴键位于 C3–C6 内。

sus2 与 sus4 的部分配音会出现相同实际琴键，例如 Csus2 与 Gsus4；保留题目指定的和弦身份及独立薄弱项。

## 作答判定与容错

- 每题单独累计新的 MIDI Note On（力度 >0），允许任意顺序的分解和弦、重复组成音、各音之间松开。Note Off、力度为 0 的 Note On、踏板以及持续按住状态不贡献答案。按设备/通道维护物理按键，尚未松开的重复 Note On 不作为新攻击。
- 在允许的窗口内，全部目标实际琴键都被弹到，且没有需要计错的错音，才计为正确。要求指定八度和转位，不把其他八度或经过音自动视为正确。
- 未演奏、部分组成音：已结束题数 +1，正确题数不增加，不变红。普通区间非目标音：立即变红，每题只增加一次薄弱等级；后来补齐也不改判。
- 训练和闯关开场均保留八拍入场：前四拍进场，触线前最后四拍显示「3、2、1、GO!」，触线时消失。首个记号与后续记号一致，检测窗口只在触线前一个三十二分音符开启；此前弹奏不计入答题。预备提示不受节拍器开关影响，手动暂停隐藏，恢复后接续。
- 两种模式提前一个三十二分音符开启检测，即 `7500 / BPM` 毫秒（90 BPM 为 83.33ms，180 BPM 为 41.67ms）。开始包含、结束不包含；B 窗口开启即结束 A 的输入归属和闯关计分，但不影响 A 继续显示和下落。
- 正常运动时每次新按键只归属当前窗口的标签。训练以最近一次作答状态为准：错音清空匹配并标红，完整重试成功后恢复正常；答对之后再弹错也会重新标红。静默、未弹全在窗口关闭时标红，不算通过。持续按住的旧音不转移给下一题，完整弹齐时不能仍按着额外非目标音。
- A 在底线前一个三十二分音符处结束窗口；正确则正常衔接 B，A 抵达底线后淡出。未答对则标红并锁定结果，忽略所有输入直到触底冻结；此时清空 A、B 的匹配及 B 的旧窗口，重试只检测 A。
- 冻结期间 A 首次重新完整弹对后保持红色并立即原位淡出，同时启动四拍预备小节（重、轻、轻、轻），屏幕中部的背景层依次显示淡灰绿色细字「3、2、1、GO!」，置于下落标签后方，不带光晕，关闭节拍器时仍显示；解冻时文字消失。预备期间整列冻结，最后一个三十二分音符开放 B 的新检测窗口；下一小节第一拍重音与 B 再次触线闪动同步，整列解冻。A 的重试输入不会转移到 B。手动暂停停止预备计拍，恢复后继续剩余拍数；速度变化按剩余拍数计算。
- 闯关错音持续到本题计分窗口结束，之后弹 B 不影响 A。退出时立即结算已开始的当前题；自然结束让最后一题完成窗口和退场，未来题不计入分母。薄弱项仅由闯关作答更新。

## 暂停、设置与自由弹奏

训练与自由弹奏暂停后显示「继续、设置、退出」，闯关仅显示「继续、退出」，不能修改设置；训练与闯关背景虚化，不展示琴键答案。

训练设置支持 40–180 BPM（加减步进 10）、节拍器与 MIDI 刷新。加减按钮触控区域为 56×56 像素，小屏下独立成行；达到上下限时禁用对应按钮。训练速度在当前页面内暂存，进入闯关固定使用 120 BPM，返回训练恢复之前的速度。恢复保留选择，已开启判定窗口不回退。节拍强拍与每个标签触线同步；训练等待重试时停拍，重试成功启动一小节预备拍，解冻第一拍只响一次重音。关闭节拍器时完全静音，预备计拍与解冻照常进行。手动暂停停止计时和声音。本地仅保存关卡最佳星级。

首页「自由弹奏」位于训练、闯关右侧。进入后上方为轨道、下方为虚拟琴键，左上角显示「自由弹奏」，不生成题目、不计分，也没有时限。点击画面暂停，退出返回首页。

## 评分

`得分 = 100 × 正确题数 / 已结算题数 × 有效秒数 / 1800`

无速度、暂停或琴键提示系数，也没有因堆叠失败强制零星的分支。

| 分数 | 星级 |
| --- | --- |
| 0 | 0 |
| 大于 0，不足 20 | 0.5 |
| 20–不足 40 | 1 |
| 40–不足 60 | 1.5 |
| 60–不足 75 | 2 |
| 75–不足 90 | 2.5 |
| 90–100 | 3 |

全对 15 分钟退出为 1.5 星，27 分钟退出为 3 星。评级使用未取整分数；显示分数向下保留一位小数。零题退出为零星，未成功连接 MIDI 不算启动。

主页仅显示半星及以上历史最佳星级；较低成绩不覆盖最佳成绩。浏览器 `voicing-stars` 只保存关卡 ID 到星级数字的映射，不保存原始答题记录、设置或评分参数。不迁移旧规则成绩，不展示规则版本标记。

## 自适应出题

- 单音训练项为具体音名，和弦为具体根音写法 × 类型 × 转位；C♯ 与 D♭ 权重完全独立，不绑定八度。同一训练项跨关卡共享薄弱等级。
- 每 10 题打乱安排 7 个均衡位置和 3 个强化机会。均衡队列为不放回洗牌袋；强化不消耗均衡条目。四个单音叶节点及单音混合分别有 4、6、10、7、17 个音名条目，Level-6 有 476 个和弦训练项；Level-3～5 在各自当前／历史题库内独立均衡抽题，强化机会仅从当题所属题库选择，保持 50% 配比。
- 薄弱等级 0–3，强化权重 0、1、3、7。按明确错音升一级，可靠完整正确降一级；等级有上限，不随时间自行降低。
- 强化候选距上次出现至少隔开 3 道题；不足则回退为均衡题。30% 是强化机会，不是保证的实际强化题比例。冷却只约束强化来源。
- 每项另有合法八度洗牌袋，优先遍历各合法八度，避免与上一题标签占用同一个实际琴键；异名同音不能绕过限制，跨八度允许。逐题生成，屏幕上已出现的题目不替换。
- 设计借鉴逐项记录和错后复习的做法，是面向连续演奏的启发式调度，不宣称为 SM-2 或 FSRS 原算法。

## MIDI 与 PWA

使用 HTTPS 或本机 localhost 连接 Web MIDI，浏览器需要提供 `navigator.requestMIDIAccess`。局域网普通 HTTP 不提供安全上下文。支持多设备、多通道、热插拔；训练进行时不显示 MIDI 按键或延音亮键，仅保留答案提示；训练暂停后实时显示按键与延音。自由弹奏始终实时显示按键；延音踏板（CC64）踩下后松键仍保持较淡亮色，松开踏板后清除延音亮键，不影响答题判定。断开或切后台清除对应输入。支持 All Sound Off、All Notes Off 和 Reset All Controllers。

启动前未连接 MIDI 的提示是网页 HTML 模态窗，不调用浏览器 alert。提示打开时背景操作不会启动或重复累计次数，关闭不自动开始训练。

通过浏览器菜单安装 PWA（Safari 可添加到主屏幕/程序坞，其他支持浏览器使用安装入口）。首次联网缓存后可离线使用。更新静态资源时递增 `dist/sw.js` 缓存版本；关闭所有旧窗口后重新打开生效，不在训练中强制刷新。

仅最终最佳星级保存在本机浏览器。设置和薄弱项仅在当前页面内存中保留，刷新恢复默认；不采集弹奏诊断数据。清除网站数据会清除星级。

应用版本由 `dist/scoring.js` 的 VERSION 与 package.json 一致管理；本次从 0.1.0 更新为 0.2.0。第二位用于功能迭代、第三位用于修复；第一位升级需用户明确同意。缓存版本是独立资源更新序号。

## 代码分层

- `performance.js`：共用的四拍时间轴、三十二分音符提前量、冻结边界、标签几何与节拍事件；不依赖 DOM 或音频设备。
- `judgment.js`：统一窗口归属；闯关累计错误与训练重试／最终状态分别处理，判题结束与标签视觉退场独立。
- `scheduler.js`：两种模式共用的题目生成器。
- `scoring.js`：闯关正确率、有效时长与星级，不参与运动或冻结。
- `app.js`：连接 MIDI、生命周期、界面及音频输出；两种模式共用队列生成、推进与绘制，不再各自维护一套下落进度。

## 和弦学习

主页「自由弹奏」替换为「和弦学习」，仅和弦类别及其转位节点显示入口，单音和综合 Level 不显示。学习无需 MIDI 即可查看；右上角设置可连接 MIDI。进入类别默认 C 原位，进入转位子节点默认对应转位，之后可自由切换。

- 17 个完整和弦名标签对应 12 个音级：七个自然音横排，五组黑键同音异名在相邻自然音之间的上方上下排列。
- 琴键上方左侧仅显示「原位／第 X 转位」，转位区只保留贯穿界面的上界线，与琴键连成整体；右侧按音高位置排列可点击圆点并以细线连接，黄色表示根音，其余绿色。琴键无音名，黄色／绿色小圆点显示 C3–C6 内的标准密集参考配音。
- MIDI 按键及踏板延音沿用蓝色琴键实时反馈，与答案圆点独立。识别支持任意 MIDI 音域、开放排列、重复八度和逐音松开的分解和弦；范围外按键不显示实时琴键反馈。
- 无检测时限。当前类别的 12 个根音候选独立累计音级和最低实际音高；非组成音清空对应候选的记录，但仍可计入其他候选。松手不清除累计，踏板不参与识别。
- 新 Note On 凑齐组成音且没有仍按住的非和弦音时，按累计最低音确定转位，立即清空所有候选。成功后的最后一个音不重复计入新轮，仍按住的音不自动带入。单纯松手不触发识别。
- 同一和弦、同一转位保持展示；不同和弦或转位才更新标签、名称及圆点。同音异名的两个标签同时高亮；增三、减七等多根音匹配优先当前根音，否则随机选择。
- 弹错、松手或长时间停顿不清除已展示的答案。手动选择、退出学习、切后台及设备断开清空识别进度。学习设置打开时暂停接收识别输入。
- 训练和闯关继续使用原有指定琴键、节拍窗口和各自错音处理规则，学习识别独立实现，不修改其成绩。

学习界面以 iPad 横屏 4:3 为基准：标签采用紧凑三排，整体位于标题下方、转位区上方，按定稿保留上部留白及标签下方间隔；矮屏横屏使用紧凑布局。
