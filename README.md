# Voicing · 和弦转位训练

面向实体钢琴或电子键盘的视觉训练工具。纯 HTML/CSS/JavaScript，无构建步骤、外部依赖、在线字体或远程资源。支持安装为 PWA，并在首次联网加载、缓存完成后离线训练。HTTP 服务用于开发和跨设备测试。

## 启动

电脑安装 Node.js 后，在项目目录运行：

```sh
npm start
```

默认监听 `0.0.0.0:8000`。终端显示本机与局域网地址。手机/平板与电脑连接同一 Wi-Fi，在 Safari 打开 LAN 地址。电脑保持运行，必要时允许系统防火墙中的 Node 入站连接。访客 Wi-Fi 的设备隔离可能阻止访问。停止服务使用 Ctrl+C。可用 `PORT=8001 npm start` 更换端口。

服务器仅提供 dist 中指定的应用文件，不暴露项目目录。请只在可信的本地网络使用，不需要设置公网端口转发。资源不会上传到任何云服务。

## 安装为 App（PWA）

- 桌面 Chrome / Edge：打开 HTTPS 部署地址（如 GitHub Pages）或本机 `http://localhost:8000`，通过地址栏安装图标、浏览器菜单或页面出现的“安装 App”按钮安装。安装入口是否出现由浏览器决定。
- 支持网页 App 的 macOS Safari 可通过“文件 → 添加到程序坞”安装。
- 安装后以独立窗口打开。首次联网加载并完成 Service Worker 缓存后可离线训练；初次使用请联网，随后关闭并重新打开一次以启用缓存。
- 普通局域网 `http://192.168.…` 地址只用于网页测试，不支持 PWA 安装和离线缓存；跨设备安装请使用 HTTPS 部署地址。
- 阶段、速度等仍保存在本机浏览器存储中，不跨设备同步。浏览器清除网站数据也会清除缓存和训练设置。
- 发布资源变更时需要递增 `dist/sw.js` 的缓存版本。新资源在联网访问时下载，关闭所有旧网页 / App 窗口后，再次打开生效，不在训练中强制刷新。

## 操作与训练规则

- 横屏，屏幕键盘为 C3–C6（含两端，共 37 键），支持 Web MIDI 输入展示，无触屏演奏或麦克风识别。
- 标记锚定根音。到达琴键上沿时在实体乐器弹奏；该时刻题目计入“已播放”，不表示答对。
- 前置关卡「00 音名识别」：看字母音名，在标签对应位置弹奏单个琴键；可选择全部 12 个键或仅 5 个黑键，范围选择保存在本机。每批各音名出现 3 次（36 / 15 题），黑键随机使用升号或降号。暂停时仅在当前目标琴键显示绿点。
- 音名标签无背景色；和弦标签保留按转位方向延伸的渐变背景（原位向右、第一转位向左、第二转位向两侧），背景随标签一起渐隐。和弦使用密集排列：第一转位根音在右、第二转位根音在中、原位根音在左。
- 训练持续出题，不设题数限制；每 36 题作为内部均衡批次，每根音 3 次。白键根音固定写作 C、D、E、F、G、A、B；五个黑键根音分别在 C♯/D♭、D♯/E♭、F♯/G♭、G♯/A♭、A♯/B♭ 中，每题独立以各 50% 的概率选择名称，不保证单批次中两种名称数量相等。
- 前置音名关卡 + 14 个和弦阶段：大三第一/第二/原位/混合；小三第一/第二/原位/混合；大三+小三；sus4 第一/第二/原位/混合；三类型综合。任意选择，无解锁限制。
- 单类型混合批次覆盖全部 36 种组合。综合批次均衡根音、类型和转位，连续完成 2 或 3 批覆盖全部 72 或 108 种组合。未完成的批次不会推进覆盖轮次。题序随机，根音八度在完整和弦不越界的候选位置中随机选择。
- 顶部显示本次有效训练时长（分:秒），暂停和切后台不计时。达到 30:00 自动停止出题并显示“本轮已完成”。重练或切换阶段重新计时。
- 默认 60 BPM，下拉可选 40–120 BPM，步长 10 BPM；每 4 拍出现一个和弦（题间隔 = 240 / BPM 秒）。每个标记提前两个出题间隔（8 拍）出现；修改 BPM 保持当前视觉进度。
- 手机（如 iPhone、Android 手机）训练时隐藏琴键，轨道占满可用高度；暂停时键盘从底部升起，所有标签一起上移并显示答案，继续时反向收回。平板和桌面保持原布局。手机模式隐藏不适用的琴键模糊开关；仍需横屏训练。
- 平板和桌面默认训练时用磨砂模糊遮挡底部琴键，暂停时在 320ms 内从模糊渐变为清晰并显示答案，恢复时从清晰渐变为模糊；可在设置中关闭“训练时模糊遮挡琴键”，选择会保存到本机。
- 训练时上方仅显示掉落轨道，点击页面任意位置（包括键盘）暂停，并在琴键上以小绿点显示当前已落地和弦的构成音（首题落地前显示首题答案）；再次点击屏幕继续。暂停时仅显示当前标签并恢复初始亮度（错音仍保留红字），隐藏其它下落标签；继续时恢复原有位置及渐隐进度。暂停时右上角显示设置图标，点击后进入设置面板，点击继续训练恢复，底部无音名键盘保持不动。支持重练、空格控制；切后台或转竖屏自动暂停。阶段、BPM 和已完成覆盖轮次尽可能存入浏览器本地存储。不同设备/访问地址之间不自动同步；本地存储不可用时仍可训练。

## MIDI 输入测试

1. 使用 HTTPS 部署地址或电脑本机 `http://localhost:8000` 打开。手机/平板访问普通局域网 HTTP 地址不满足 Web MIDI 的安全上下文要求。
2. 连接实体 MIDI 键盘，在准备训练或暂停后的设置面板点击「连接 MIDI」，允许浏览器访问。支持同时接收所有已连接输入、所有通道，以及设备热插拔。
3. 在准备界面或暂停状态弹奏：C3–C6 内的琴键变蓝，松键恢复；绿色答案点保留。范围外的音显示数量，不折叠到其他八度。力度为零的 Note On 按松键处理；延音踏板不延长物理按键高亮。
4. 训练中继续接收按键状态，暂停后展示当前仍按住的键，不会启动训练或发声；有效判定时段内，标签触线后开始渐隐，无论未弹奏还是弹对都继续渐隐；按标签对应的实际琴键判定（和弦任一构成音即可），出现任何错音则立即恢复为清晰红字并保持到下一标签触线；触线前后各 180 毫秒不判对错，松键、踏板和暂停期间不判定。切后台、设备断开会清除对应亮键；如设备漏发松键信号，可在设置中点击「清除亮键」。
5. iPhone/iPad、桌面 Chrome/Safari 均检测实际 `navigator.requestMIDIAccess` 能力。浏览器或扩展需提供 Web MIDI 接口，名称本身不代表支持；不支持、权限拒绝、未连接设备分别显示提示。启用提供 MIDI 的扩展后可再次点击连接重试。

自动测试使用模拟 MIDI 设备和消息；真实设备连接与不同浏览器的权限流程需实机验证。已安装 PWA 请联网打开，关闭所有旧窗口再重新打开以更新缓存。

## 验证

```sh

```

自动验证训练顺序、每轮分布、跨轮覆盖和音域边界。真实 iPhone/iPad 的 Safari 横屏、后台切换和网络访问仍需在设备上验证。
