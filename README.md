# Voicing · 和弦转位训练

面向实体钢琴或电子键盘的视觉训练工具。纯 HTML/CSS/JavaScript，无构建步骤、外部依赖、在线字体或远程资源。支持安装为 PWA，并在首次联网加载、缓存完成后离线训练。HTTP 服务用于开发和跨设备测试。

## 启动

电脑安装 Node.js 后，在项目目录运行：

```sh
npm start
```

默认监听 `0.0.0.0:8000`。终端显示本机与局域网地址。手机/平板与电脑连接同一 Wi-Fi，在 Safari 打开 LAN 地址。电脑保持运行，必要时允许系统防火墙中的 Node 入站连接。访客 Wi-Fi 的设备隔离可能阻止访问。停止服务使用 Ctrl+C。可用 `PORT=8001 npm start` 更换端口。

服务器仅提供 dist 中指定的应用文件，不暴露项目目录。请只在可信的本地网络使用，不需要设置公网端口转发。资源不会上传到任何云服务。

## 安装为 App（PWA）

- 桌面 Chrome / Edge：打开 HTTPS 部署地址（如 GitHub Pages）或本机 `http://localhost:8000`，通过地址栏安装图标、浏览器菜单或页面出现的“安装 App”按钮安装。安装入口是否出现由浏览器决定。
- 支持网页 App 的 macOS Safari 可通过“文件 → 添加到程序坞”安装。
- 安装后以独立窗口打开。首次联网加载并完成 Service Worker 缓存后可离线训练；初次使用请联网，随后关闭并重新打开一次以启用缓存。
- 普通局域网 `http://192.168.…` 地址只用于网页测试，不支持 PWA 安装和离线缓存；跨设备安装请使用 HTTPS 部署地址。
- 阶段、速度等仍保存在本机浏览器存储中，不跨设备同步。浏览器清除网站数据也会清除缓存和训练设置。
- 发布资源变更时需要递增 `dist/sw.js` 的缓存版本。新资源在联网访问时下载，关闭所有旧网页 / App 窗口后，再次打开生效，不在训练中强制刷新。

## 操作与训练规则

- 横屏，屏幕键盘为 C3–C6（含两端，共 37 键），仅作参照，无触屏演奏、MIDI 或麦克风识别。
- 标记锚定根音。到达琴键上沿时在实体乐器弹奏；该时刻题目计入“已播放”，不表示答对。
- 密集排列：第一转位根音在右、背景向左；第二转位根音在中、背景向两侧；原位根音在左、背景向右。每侧背景固定约两个白键宽，不给出构成音落点。
- 训练持续出题，不设题数限制；每 36 题作为内部均衡批次，每根音 3 次。白键根音固定写作 C、D、E、F、G、A、B；五个黑键根音分别在 C♯/D♭、D♯/E♭、F♯/G♭、G♯/A♭、A♯/B♭ 中，每题独立以各 50% 的概率选择名称，不保证单批次中两种名称数量相等。
- 14 阶段：大三第一/第二/原位/混合；小三第一/第二/原位/混合；大三+小三；sus4 第一/第二/原位/混合；三类型综合。任意选择，无解锁限制。
- 单类型混合批次覆盖全部 36 种组合。综合批次均衡根音、类型和转位，连续完成 2 或 3 批覆盖全部 72 或 108 种组合。未完成的批次不会推进覆盖轮次。题序随机，根音八度在完整和弦不越界的候选位置中随机选择。
- 顶部显示本次有效训练时长（分:秒），暂停和切后台不计时。达到 30:00 自动停止出题并显示“本轮已完成”。重练或切换阶段重新计时。
- 默认 60 BPM，下拉可选 40–120 BPM，步长 10 BPM；每 4 拍出现一个和弦（题间隔 = 240 / BPM 秒）。每个标记提前两个出题间隔（8 拍）出现；修改 BPM 保持当前视觉进度。
- 默认训练时用磨砂模糊遮挡底部琴键，暂停后立即清晰显示琴键和答案；可在设置中关闭“训练时模糊遮挡琴键”，选择会保存到本机。
- 训练时上方仅显示掉落轨道，点击页面任意位置（包括键盘）暂停，并在琴键上以小绿点显示当前已落地和弦的构成音（首题落地前显示首题答案）；再次点击屏幕继续。暂停时右上角显示设置图标，点击后进入设置面板，点击继续训练恢复，底部无音名键盘保持不动。支持重练、空格控制；切后台或转竖屏自动暂停。阶段、BPM 和已完成覆盖轮次尽可能存入浏览器本地存储。不同设备/访问地址之间不自动同步；本地存储不可用时仍可训练。

## 验证

```sh
npm test
```

自动验证训练顺序、每轮分布、跨轮覆盖和音域边界。真实 iPhone/iPad 的 Safari 横屏、后台切换和网络访问仍需在设备上验证。
